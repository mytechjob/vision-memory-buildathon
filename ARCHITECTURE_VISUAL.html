🔄 File Processing Flow

📤 File Upload & Validation

Format Check: PNG, JPG, JPEG, WebP, HEIC
Size Validation: Min 50x50px, File size limits
Corruption Check: PIL load test, error handling

⚙️ Processing Mode Selection

🚀 Ultra Fast: OCR only, minimal processing
⚖️ Balanced: OCR + basic AI analysis
🔍 Detailed: Full OCR + AI vision analysis

🔄 Parallel Processing

OCR Branch: Preprocessing → Tesseract → Text cleanup
Vision Branch: AI service → Visual description
Thumbnails: Resize → Aspect ratio → Base64

📊 Data Aggregation & Storage

Combine Results: OCR + Visual + Metadata
DataFrame Storage: Structured session data
Search Index: TF-IDF matrix build

🔍 Search Operation Flow

📝 Query Preprocessing

Input: Natural language query → Clean: Normalize text → Mode: Combined/Text/Visual → Parameters: Max results, confidence threshold

🧮 Similarity Calculation

Vectorize: TF-IDF features → Compare: Cosine similarity → Score: 0.0-1.0 range → Rank: Best matches first

📈 Result Processing

Normalize: 0-100% confidence → Explain: Match reasoning → Format: Display-ready results → Limit: Top N results
